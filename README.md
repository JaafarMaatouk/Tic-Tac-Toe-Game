# Tic-Tac-Toe Game (C# WinForms)

A desktop-based Tic-Tac-Toe game developed using C# and Windows Forms (WinForms). The application features a modern, user-friendly interface with complete game logic for a two-player experience.

## Project Overview
This project demonstrates the transition from console-based logic to Graphical User Interface (GUI) programming. It focuses on event-driven programming, UI state management, and clean game logic implementation.

## Features
- **Two-Player Mode:** Players take turns placing 'X' and 'O' on a 3x3 grid.
- **Win & Draw Detection:** Automatically detects the winner when a player gets three identical symbols in a row, column, or diagonal, and announces a draw if the board is full.
- **Visual Feedback:** Highlights the winning row/column with a color change for immediate visual feedback.
- **Restart Button:** Allows players to reset the board and start a new game instantly.
- **Clean Interface:** Uses a dark, modern theme for better visibility and user experience.

## Technical Details
- **Language:** C#
- **Framework:** Windows Forms (WinForms)
- **Event-Driven Programming:** Utilizes button click events to handle player moves and update the UI in real-time.
- **Game Logic:** Implements matrix-based checking for win conditions.

## How to Run
1. Clone this repository or download it as a ZIP file.
2. Open the `.sln` file in **Visual Studio**.
3. Press `F5` or `Ctrl + F5` to build and run the application.
4. Click on any empty cell to start playing.
